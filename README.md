# brainrotchess

A TypeScript project featuring chess gameplay with AI integration.

## Installation

```bash
npm install @alexsebastian98/brainrotchess
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Scripts

- `dev` - Start development server
- `build` - Build for production
- `preview` - Preview production build
- `start` - Start server
- `clean` - Clean build artifacts
- `lint` - Run TypeScript linter
